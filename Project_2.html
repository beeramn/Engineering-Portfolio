U-Net Audio Stem Separator

A lightweight, stereo-aware U-Net that estimates vocal and instrumental stems from a song. The project combines a curated music dataset, spectrogram processing, custom model training, and audio reconstruction in an end-to-end separation workflow.

Project Overview

Goal

Build a transparent, reproducible, and accessible source-separation system that can produce vocal and instrumental stems without relying on a large commercial model. The model is intentionally compact: the focus is demonstrating the core ideas of modern source separation under limited compute.

End-to-End System

Audio is converted into normalized stereo magnitude spectrograms. A custom U-Net predicts soft masks for vocals and instrumentals, and the inference pipeline applies those masks and reconstructs the separated audio. Training and evaluation use paired mixtures and target stems.

Design Constraint

Training experiments encountered GPU memory limits. The final configuration uses a smaller base width, shorter audio segments, and a lower FFT size to make training practical while preserving stereo structure and the two-stem objective.

Data and Preprocessing Workflow

Dataset Curation

The training set combines MUSDB18 with additional tracks curated through web scraping to broaden exposure to modern music and genres. Tracks are organized as mixture.wav, vocals.wav, and instrumental.wav at 44.1 kHz. The dataset loader automatically creates 70% training, 15% validation, and 15% test splits.

Building Instrumental Targets

MUSDB18 provides separate bass, drums, other, vocals, and mixture files. The data/merge-tracks.py script combines bass, drums, and other into a single instrumental target, matching the project's two-stem output.

Audio Features

Audio is loaded as channel-first PyTorch tensors and resampled when needed. Preprocessing computes the short-time Fourier transform, separates magnitude and phase, and standardizes magnitude spectrograms per frequency bin using mean and standard deviation.

Training Targets and Augmentation

Soft ratio masks are computed from the vocal and instrumental magnitudes relative to the mixture. Simple pitch shifts and frequency masking augment the training audio. Mixture phase and normalization statistics are retained for inference-time reconstruction.

The dataset is not bundled in the repository because of its size; the README points to the download information in ATTRIBUTION.md.

Stereo U-Net Architecture

The model treats a stereo magnitude spectrogram as a two-channel image. It learns time-frequency patterns alongside relationships between the left and right audio channels.

Encoder and Bottleneck

Two downsampling levels capture progressively broader context. The bottleneck forms a compact representation of the mixture spectrogram. Convolutional blocks use depthwise-separable operations and normalization layers.

Decoder and Skip Connections

The decoder upsamples the learned features and combines them with earlier encoder activations through custom skip connections, restoring fine time-frequency detail for mask prediction.

Four Soft Masks

A final 1×1 convolution predicts four masks: left and right vocal masks plus left and right instrumental masks. A sigmoid constrains each mask to the 0–1 range for multiplicative masking.

Model Tensors

The model accepts magnitude inputs shaped (B, 2, F, T) and predicts masks shaped (B, 2 stems, 2 channels, F, T), where the stem dimension represents vocals and instrumentals.

The two-level design and base_channels=8 configuration were selected to fit limited GPU memory while retaining stereo information.

Training and Compute Tuning

Training Pipeline

PyTorch DataLoaders provide batching, shuffling, and optional worker processes. The training loop predicts vocal and instrumental masks and optimizes L1 mask-regression loss. AdamW and a ReduceLROnPlateau scheduler adjust optimization as validation loss changes. Dropout, weight decay, gradient clipping, and early stopping support stable training; mixed-precision training is available when CUDA is available.

GPU Training and Checkpoints

Model training ran on GPU nodes in the Duke Compute Cluster using SLURM. The best checkpoint is saved when validation improves, and a final checkpoint is also retained with model and optimizer state, training curves, configuration, and epoch metadata.

Evaluation Results

The model was evaluated on a subset of MUSDB18 test tracks. For scoring, the bass, drums, and other reference stems were merged into an instrumental target. Scores were computed per song and averaged across the evaluated subset.

What the Results Show

Instrumental separation performed better than vocal isolation, especially on SI-SDR. This is a known challenge for a small U-Net trained with limited data. The results point to vocal clarity as the main opportunity for improvement, through a larger dataset, model refinements, or a loss function designed more directly around vocal quality.

Run Inference

Install the listed Python dependencies, then pass a WAV file to the inference script:

pip install torch torchaudio soundfile numpy librosa tqdm matplotlib python inference.py path/to/song.wav

See SETUP.md for setup details. Inference uses chunking, Wiener filtering, and inverse STFT reconstruction to produce the separated stems.
